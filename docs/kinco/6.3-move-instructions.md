The FILL instruction sets the N number of successive variables, beginning with the address OUT, to the specified constant IN.

OUT is the starting address of a memory block with variable length. Please be noted that the memory block must be in the legal memory area, otherwise the consequences may be terrible.

  LD

If EN is 1, this instruction is executed.

  IL

If the CR is 1, this instruction is executed, and it does not influence the CR.

**Examples**

LD

%SM0.0 is always ON, therefore the FILL is always executed: 10 variables from %VB10 to %VB19 are all set to B#0.

IL

RESULT

VB10 to %VB19 are all set to B#0.

```text
FILL B#0, %VB10, B#10 (* 10 variables from %VB10 to %VB19 are all set to B#0 *)
```

```text
FILL B#0, %VB10, B#10	(* If the CR is 1, 10 variables from %VB10 to %VB19 are all set to B#0 *)
```

(* If the CR is 0, this statement is not executed *)
